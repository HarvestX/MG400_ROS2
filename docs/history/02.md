# 02 ServoMode Plugin Guard

## 実装内容

- `mg400_interface::MG400Interface` に ServoMode guard を追加した。
  - `setServoModeActive()` / `isServoModeActive()` で ServoMode active 状態を thread-safe に共有する。
  - `requestServoModeExit()` と callback により、plugin から `mg400_node` 側の `exitServoMode()` を要求できるようにした。
  - `setServoExitOnDashboardStopCommand()` / `shouldExitServoModeOnDashboardStopCommand()` で dashboard stop 系 command 時の自動 exit を制御できるようにした。
- `mg400_node` と `MG400Interface` の ServoMode 状態を同期するようにした。
  - ServoMode enter 成功時に interface guard を active にする。
  - ServoMode exit、lifecycle 遷移、接続断時に interface guard を inactive に戻す。
  - `servo_exit_on_dashboard_stop_command` parameter を追加し、デフォルトを `true` とした。
- 通常 motion plugin に ServoMode active 中の排他 guard を追加した。
  - `MovJ` / `MovL` / `MovJIO` / `MovLIO` / `JointMovJ` は goal 受理時に reject する。
  - 同 action は実行スレッドで motion command を送る直前にも guard を確認し、ServoMode active なら abort する。
  - `MoveJog` service は ServoMode active 中に送信せず、`error_id=-2` を返す。
  - `CommandQueue` は goal 受理時、実行開始時、batch 送信前、各 command 送信前に guard を確認する。
- dashboard stop 系 plugin に ServoMode 自動 exit を追加した。
  - `DisableRobot` / `EmergencyStop` / `ResetRobot` は command 実行前に ServoMode exit を要求する。
  - `servo_exit_on_dashboard_stop_command=false` の場合は自動 exit を行わない。
- `mg400_interface` に ServoMode guard API の単体テストを追加した。

## 仕様メモ

- ServoMode の所有者は引き続き `mg400_node` とし、plugin は `MG400Interface` の guard を参照する。
- dashboard stop 系 command は安全上 ServoMode を継続できないため、command 送信前に exit する。
- 通常 motion command と ServoJ/ServoP stream は同時に送らない。ServoMode を抜けてから通常 motion command を実行する運用にする。
