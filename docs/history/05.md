# 05 Separate RViz Servo Panel

## 変更内容

- ServoMode / ServoP 操作を `Mg400ControllerPanel` から独立させ、`Mg400ServoPanel` を追加した。
  - RViz plugin 名は `mg400_rviz_plugin/Mg400Servo`。
  - Controller panel は Enable / Disable / ClearError / motion params / MovJ / MovL / JointMovJ / MoveJog の通常操作だけを扱う。
- `Mg400ServoPanel` は ServoMode と ServoP / ServoJ target 操作を扱う。
  - `servo_mode` service で ServoMode へ enter / exit する。
  - `servo_mode_enabled` topic を購読し、外部変更も panel 状態に反映する。
  - ServoMode enter 成功時、または `servo_mode_enabled=true` 遷移時に、最新 realtime feedback の `tool_vector_actual` から仮想 target pose を初期化する。
  - X / Y / Z / Rx の +/- ボタンを押している間だけ仮想 target を更新する。
  - J1 / J2 / J3 / J4 の +/- ボタンを押している間だけ仮想 joint target を更新する。
  - `t`, `aheadtime`, `gain` の入力欄は設けず、message field には常に `0.0` を入れる。
  - ServoMode active 中は 15 ms 周期で `servo_p` または `servo_j` を publish する。
- RViz plugin 全体の pose 軸表記を `X` / `Y` / `Z` / `Rx` に統一した。
  - Controller panel の MovJ / MovL 姿勢入力は `Rx` 表示にする。
  - Controller panel の MoveJog 姿勢操作は `Rx+` / `Rx-` を送る。
  - Monitor panel の TCP summary も `X` / `Y` / `Z` / `Rx` 表示にする。
- `mg400_rviz_plugin` に `std_msgs` dependency を追加した。

## 仕様メモ

- RViz panel 内部の仮想 target は ROS 単位で保持する。
  - position: meter
  - orientation: quaternion
- RViz UI の速度入力は operator 向けに mm/s と deg/s とし、target 更新時に m/s と rad/s に変換する。
- `servo_p` publish では `PoseStamped` を ROS 単位のまま publish し、TCP 単位変換は `mg400_node` / `mg400_interface` 側で行う。
- `servo_j` publish では joint target を radian のまま publish し、TCP 単位変換は `mg400_node` / `mg400_interface` 側で行う。
- `pose.header.frame_id` は `mg400_origin_link` とする。

## 残タスク

- MG400 実機で ServoMode enter 直後の初期 target と実 TCP pose が一致することを確認する。
- ServoP Target の初期速度値が実機操作として適切か確認する。
- `mg400_node` 側で `prefix` を使う構成の場合、Servo panel の frame_id 指定方法を追加で検討する。
