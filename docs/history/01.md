# 01 ServoMode Node Core

## 実装内容

- `mg400_node` に ServoMode の内部状態を追加した。
  - `inactive` / `active` を node 内で保持する。
  - ServoMode session 内で最初に受けた有効 command 種別を `servo_j` または `servo_p` に固定する。
  - 別種の command が同一 session 内で届いた場合は送信せず warning を出す。
- `servo_mode` service server を追加した。
  - `enable=true` で ServoMode enter を要求する。
  - `enable=false` で ServoMode exit を要求する。
  - lifecycle node が active でない場合、未接続の場合、realtime feedback が未取得の場合は enter を拒否する。
  - enter 時は realtime feedback の `robot_mode == ENABLE`, `enable_status != 0`, `error_status == 0` を確認する。
  - enter 時に `GetErrorID()` を確認し、controller / servo error が残っている場合は enter を拒否する。
- `servo_mode_enabled` state topic を追加した。
  - QoS は `KeepLast(1)`, reliable, transient local とした。
  - configure 時と ServoMode の入退場時に現在状態を publish する。
- `servo_j` / `servo_p` subscription を追加した。
  - QoS は `KeepLast(1)`, volatile とした。
  - `servo_qos_reliable=false` の場合は best effort、true の場合は reliable にする。
  - ServoMode inactive 中の command は破棄する。
  - ServoMode active 中だけ `MotionCommander::servoJ()` / `servoP()` を呼ぶ。
- Servo command timeout を追加した。
  - `servo_command_timeout_ms` parameter を追加し、デフォルトを 100 ms とした。
  - ServoMode enter 後、一定時間 valid command が届かない場合は ServoMode を inactive に戻す。
- realtime feedback による ServoMode exit を追加した。
  - `robot_mode == ERROR`
  - `error_status != 0`
  - `enable_status == 0`
- lifecycle / connection 断で ServoMode を必ず exit するようにした。
  - deactivate / cleanup / shutdown / error
  - `MG400Interface::ok()` が false になった場合
- `ServoP` の quaternion を roll / pitch / yaw に変換して `MotionCommander::servoP()` に渡すようにした。
  - 初期実装では `pose.header.frame_id` が `<prefix>mg400_origin_link` の場合だけ受け付ける。

## 追加パラメータ

- `servo_command_timeout_ms`: valid command 未受信時に ServoMode を exit するまでの時間。デフォルト 100。
- `servo_expected_period_ms`: 宣言のみ。RViz plugin の publish 周期は panel 側の 15 ms タイマで決まる。
- `servo_qos_reliable`: `servo_j` / `servo_p` command topic の QoS reliability。デフォルト false。

## 未実装

- `DisableRobot` / `EmergencyStop` / `ResetRobot` など dashboard stop 系 command 受理時の ServoMode 自動 exit。
- `ServoP` で origin frame 以外を受けるための TF lookup。
- Dobot response の `ResultID` / `ErrorID` の非同期監視。
- MG400 実機での `ServoP` Rx/Ry の挙動確認。
