# 04 RViz ServoP Control Panel

## 実装内容

- `mg400_rviz_plugin::Mg400ControllerPanel` に ServoMode 操作用 UI を追加した。
  - Robot section に `Enter ServoMode` / `Exit ServoMode` ボタンを追加した。
  - `servo_mode` service を呼び出して ServoMode の入退場を行う。
  - `servo_mode_enabled` topic を購読し、外部からの ServoMode 状態変更も UI に反映する。
- RViz plugin 内に ServoP 用の仮想目標 pose を保持するようにした。
  - ServoMode enter 成功直後、または `servo_mode_enabled=true` への遷移検出時に、最新 realtime feedback の `tool_vector_actual` から仮想目標を初期化する。
  - 初期化時の frame は `mg400_origin_link` とし、ServoP publish でも同じ frame を使う。
- `ServoP Target` section を追加した。
  - X / Y / Z / Rx の +/- ボタンを押している間、仮想目標を指定速度で更新する。
  - Linear speed は mm/s、Angular speed は deg/s で調整できる。
  - ServoMode active 中は通常 MovJ / MovL / JointMovJ / MoveJog UI を無効化し、ServoP target 操作だけを有効化する。
- ServoMode active 中、15 ms 周期で現在の仮想目標を `servo_p` topic へ publish する。
  - `t`: 0.0
  - `aheadtime`: 0.0
  - `gain`: 0.0
  - MG400 へ送る TCP command 文字列に `t` / `aheadtime` / `gain` は含めない。
  - MG400 の単一 tool 姿勢角は TCP ServoP の `Rx` slot に入れる。
