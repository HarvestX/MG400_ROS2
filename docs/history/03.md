# 03 ServoP Frame Policy

## 決定内容

- `ServoP` は `<prefix>mg400_origin_link` の pose だけを受け付ける。
- `mg400_origin_link` 以外の `pose.header.frame_id` は TF 変換せず reject する。
- `servo_allow_tf_transform` parameter は追加しない。
- 15 ms 周期の ServoP stream では callback 内の TF lookup を避け、publisher 側で origin frame に変換してから publish する運用にする。

## 次に実装する内容

- Dobot response の `ResultID` / `ErrorID` を監視する非同期 response reader を検討・実装する。
- `ServoJ` / `ServoP` response で `ErrorID != 0` を検出した場合、ServoMode を exit する。
- 15 ms 周期の command callback を長時間 block しないよう、Motion TCP 送信経路とは分離して短い timeout または非同期読み取りで扱う。
