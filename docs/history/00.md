# 00 ServoMode Interface Foundation

## 実装内容

- `mg400_msgs/msg/ServoJ.msg` を追加した。
  - `joint_angles` は既存 `JointMovJ` と同じく ROS 側では radian の `float64[4]` とした。
  - TCP/IP の `ServoJ` 文字列では J5/J6 を `0.000,0.000` でゼロ埋めする。
  - `t` / `aheadtime` / `gain` は互換性維持用の field として残し、`set_*` フラグは持たせない。
- `mg400_msgs/msg/ServoP.msg` を追加した。
  - 目標姿勢は既存 motion API に合わせて `geometry_msgs/PoseStamped` とした。
  - `t` / `aheadtime` / `gain` は互換性維持用の field として残す。
- `mg400_msgs/srv/ServoMode.srv` を追加した。
  - `enable` で ServoMode の入退場を要求する。
  - response は `error_id` と `message` を返す形にした。
- `mg400_interface::CommandBuilder` に `buildServoJ()` / `buildServoP()` を追加した。
  - ROS 側の m / radian を TCP/IP 仕様の mm / degree に変換する。
  - TCP command 文字列に `t`, `aheadtime`, `gain` は含めない。
- `mg400_interface::MotionCommander` に `servoJ()` / `servoP()` を追加した。
  - Motion TCP port へ `ServoJ(...)` / `ServoP(...)` を送信する。
  - `t`, `aheadtime`, `gain` は TCP command 文字列へ反映しない。
- `test_motion_commander` に Servo command の文字列生成・送信・未使用 field 無視のテストを追加した。

## 仕様メモ

- `set_t` / `set_aheadtime` / `set_gain` は使わない。
- publisher は `t` / `aheadtime` / `gain` に `0.0` を入れて publish する。
- `mg400_node` は `t` / `aheadtime` / `gain` にゼロ以外の値を受信した場合、warning を出して無視する。

## 次に実装する内容

- `mg400_node` に ServoMode の内部状態、service server、state publisher を追加する。
- `servo_j` / `servo_p` subscription を追加し、ServoMode active 中だけ `MotionCommander::servoJ()` / `servoP()` を呼ぶ。
- realtime feedback の `robot_mode`, `enable_status`, `error_status` を使って ServoMode enter / exit 条件を実装する。
- command timeout と lifecycle deactivate / cleanup / shutdown / error 時の ServoMode exit を実装する。
